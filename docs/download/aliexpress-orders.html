How to download your AliExpress order receipts

AliExpress keeps your order history in your account, but the receipt for each order lives on its own screen and there is no way to take the lot with you.

What you get

Habeas is an open-source browser extension that collects your documents from AliExpress and saves them wherever you choose. From this source it extracts:

  • order receipts — each purchase with its date, amount, currency, store and category.

What AliExpress actually gives you

AliExpress records each order with its date, total, currency and the shop that sold it, and separately holds the receipt detail behind a second call. Habeas puts the two together, so an order arrives already carrying the receipt information rather than a bare line you would still have to open.

Worth knowing about this source

  • AliExpress does not expose a REST API: its web app talks to Alibaba's mtop gateway with signed requests. Habeas issues those same signed calls from the session you already have open.
  • Orders do not arrive as a list. They come back as dynamically named fields inside a single blob, so the source collects them by key prefix rather than by position.
  • The receipt detail is a separate request per order, so a long history takes proportionally longer here than on a source that returns everything in one page.

How it works

It is not a service that connects to aliexpress.com on its own. It runs inside your own browser, reusing the session you already have open:

  1. You go to aliexpress.com and sign in yourself, as always, with your MFA or whatever code you use.
  2. Habeas reuses that already-authenticated session to request your documents, exactly as the site itself does.
  3. You choose the destination: a download, a local folder, your Google Drive, Dropbox, WebDAV, S3 or an endpoint of your own.

Your password is never read, never stored and never sent anywhere, and nothing runs in the background while you are away. This is a community source: its definition is public and reviewable, and it runs under the same security rules as every other.

Install on Chrome Install on Firefox

Free and open source (AGPL-3.0). Install the extension and enable the “AliExpress” source from Settings → Browse sources.

Chrome will warn you that the extension is not trusted. That happens to any developer account recently registered on the Chrome Web Store, it fades after a few months, and it says nothing about the code — which you can read in full.

Frequently asked questions

Does Habeas store my AliExpress password?

No. You sign in yourself, on the usual website, including any verification code. Habeas reuses the session your browser already has open and never reads or stores your credentials.

Is my data sent to a server?

No. Everything happens inside your browser. Documents only go to the destination you pick: a download, a folder on your machine, your own Google Drive or Dropbox, or an endpoint you configure.

What format do I get the documents in?

The original documents exactly as the service issues them (HTML), together with a manifest holding the normalised data.

Is it free?

Yes. Habeas is free software under the AGPL-3.0 licence and its code is public on GitHub.

Your service is not on the list?

Habeas can learn a new one without any code. Record mode watches the site’s own API while you browse it normally and drafts the source for you; you test it against your own account, and then keep it to yourself or share it so everyone gets it. That is where most of the catalog came from.
