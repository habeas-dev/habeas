How to download your documents, service by service

A guide per service: what Habeas extracts from it, in what formats, and what it does not cover.

Install on Chrome Install on Firefox

Free and open source (AGPL-3.0). Install it, then turn on the source you need from Settings → Browse sources. Chrome will warn you that the extension is not trusted. That happens to any developer account recently registered on the Chrome Web Store, it fades after a few months, and it says nothing about the code — which you can read in full.

Your service is not on the list?

Habeas can learn a new one without any code. Record mode watches the site’s own API while you browse it normally and drafts the source for you; you test it against your own account, and then keep it to yourself or share it so everyone gets it. That is where most of the catalog came from.
