American Express — experimental source, not yet verified

A draft definition for American Express. Nobody has run it against a real account yet, so it may extract nothing at all. This page exists so that somebody who HAS an account can try it and say what happened.

Do not expect this to work

This source was drafted from woob — American Express module — a map of which endpoints the service uses and what they return — and has never been validated against a live session. Endpoints move, responses change shape, and a definition written from a reference rather than from a capture is a hypothesis. Installing it is safe; the same rules apply as to any other source. It simply may not find anything.

What it is meant to extract

  • each movement with its date, amount, currency, description and counterparty

If you have an account here

Install it, run it once, and open an issue with what happened — including "nothing at all", which is the most useful answer of the three. That is how a draft becomes a verified source, and it is the only way: the project cannot test an account it does not have.
