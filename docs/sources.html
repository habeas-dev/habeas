Catalogue

Your documents, on your disk.

Every source is a readable file stating exactly which service it talks to and what it extracts — as data, never code. Install one from the extension in a click. First-party sources are written and verified by the project; community ones are contributed and open to scrutiny.

Browse the how-to guides →

Install on Chrome Install on Firefox

Free and open source (AGPL-3.0). Chrome will warn you that the extension is not trusted: that happens to any developer account recently registered on the Chrome Web Store, it fades after a few months, and it says nothing about the code — which you can read in full.
